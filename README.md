# API de reservas

API para administrar citas de una barbería. Está hecha con Node.js, Express y MySQL.

## Funciones

- Consultar las citas registradas.
- Registrar una cita.
- Modificar una cita.
- Cancelar una cita sin borrar su historial.
- Evitar que dos citas activas ocupen la misma fecha y hora.

## Herramientas

- Node.js
- Express
- MySQL
- mysql2
- dotenv
